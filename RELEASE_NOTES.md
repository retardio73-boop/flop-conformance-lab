# v0.1.4-alpha

Cross-system evidence release for FLOP Conformance Lab.

## Included

- Public `quote -> open_channel -> receipt` fixture derived from the interoperability gap discussed in Yellow Paper issue #26. The fixture preserves unit/profile semantics and fails closed where the public spec does not yet define a canonical pre-session quote/discovery object or normalized pay-unit mapping.
- Independent reproduction of Yellow Paper issue #44 (`wrong_path_orientation`), including a control mutation that distinguishes a duplicated odd Merkle node from a genuinely orientation-sensitive level.
- Existing released-TCLK, canonicalization, Technocore-signature, signing-boundary, settlement-reference and Router-integration lanes.
- Cross-system scope is explicit: the Lab does not attempt to replace generic Technocore server conformance harnesses.

## Alpha limitations

- `RELEASE_CONFORMANCE = ACTIVE` against pinned `@flop-labs/tclk@0.1.0` vectors.
- `UPSTREAM_CONFORMANCE = MANIFEST_ONLY`; upstream SHAs/issues are evidence sources, not silently normative behavior.
- FLOP live-runtime conformance remains `PUBLIC_RUNTIME_UNAVAILABLE`.
- `quote -> open_channel` remains fail-closed until a canonical/versioned quote contract exists.
- No live settlement, production wallet, productive signing key, passphrase or API key is included in the package.

## Upstream evidence

- Yellow Paper #26: Router evidence for incomparable quote units and the resulting public boundary fixture.
- Yellow Paper #44: independent reproduction of the published `wrong_path_orientation` corpus discrepancy.

Artifacts and SHA-256 checksums should be generated by the release workflow/build from the exact tagged commit; no checksum is predeclared here before packaging.
